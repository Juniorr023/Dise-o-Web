# 🎨 Diseño Web - Prácticas de HTML, CSS y JavaScript

Bienvenido a este repositorio de **Diseño Web**. Es un proyecto educativo que contiene prácticas y ejercicios de desarrollo web frontend usando **HTML**, **CSS**, **JavaScript** y **React**.

## 📚 Descripción

Este repositorio documenta mi progreso en el aprendizaje de diseño web, desde conceptos básicos hasta proyectos más complejos con React y Vite. Incluye prácticas organizadas por días de estudio, cada una enfocada en diferentes aspectos del desarrollo frontend.

## 🚀 Cómo Usar Este Repositorio

### Requisitos Previos
- Node.js (v14 o superior)
- npm o yarn
- Un navegador web moderno
- Git

### Instalación y Ejecución

#### Para prácticas simples (HTML/CSS/JS):

1. Clona el repositorio:
```bash
git clone https://github.com/Juniorr023/Dise-o-Web.git
cd Dise-o-Web
```

2. Navega a la carpeta de la práctica deseada:
```bash
cd dia1/practica1
```

3. Abre el archivo `index.html` en tu navegador, o usa un servidor local:
```bash
# Usando Python
python -m http.server 8000

# Usando Node.js (http-server)
npx http-server
```

#### Para proyectos React (dia23+):

1. Navega a la carpeta del proyecto:
```bash
cd dia23/mi_app_2
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

4. Abre tu navegador en `http://localhost:5173`
